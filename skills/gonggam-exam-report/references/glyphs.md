# 쓸 수 있는 글자 — 기호 규격

동봉 폰트(`assets/fonts/NotoSansKR-400/700/900.woff2`)에 **있는 글자만** 리포트에 넣는다.
없는 글자가 하나라도 있으면 렌더가 막힌다. 막는 것이 맞다 — 두부(`□`)로 인쇄된 리포트가
원장님께 나가는 것보다 낫다. 다만 막힐 이유를 미리 없애자는 것이 이 문서다.

> **주석에도 특수 기호를 쓰지 않는다.** 아래 §3 을 반드시 읽을 것. 오늘 세 번 중 두 번이
> 주석 때문이었다.

세 굵기(400·700·900)의 글자표는 **완전히 같다** (각 23,174자, 차이 0). 400 에서 되면 셋 다 된다.

---

## 2. 없는 것 — 대체표 (정본)

**이 표가 실패 메시지의 근거다.** `subset_font.py` 가 이 표를 그대로 읽어 «무엇으로
바꾸면 되는지» 를 말한다(`substitutions()`). 줄 꼴을 바꾸지 말 것 —
`| 글자 | U+코드 | 대신 쓸 것 | 비고 |`, 첫 칸의 글자와 둘째 칸의 코드가 맞아야 한 줄로 읽힌다.

| 없는 글자 | 코드 | 대신 쓸 것 | 비고 |
|---|---|---|---|
| ✗ | U+2717 | `×` (U+00D7) | 가장 자주 걸린다. `✓` 는 있고 `✗` 는 없다 |
| ✘ | U+2718 | `×` (U+00D7) | 위와 같다 |
| ✔ | U+2714 | `✓` (U+2713) | 굵은 체크는 없다. 가는 체크만 있다 |
| ✅ | U+2705 | `✓` (U+2713) | 이모지는 전부 없다 |
| ❌ | U+274C | `×` (U+00D7) | 이모지 |
| ⭕ | U+2B55 | `○` (U+25CB) | 이모지 |
| ⛔ | U+26D4 | 글자 없이 굵게 쓰거나 `※` (U+203B) | 판형 주석에서 렌더를 죽인 그 글자 |
| ☑ | U+2611 | `[✓]` 로 풀어 쓰기 | 네모 안 체크는 없다 |
| ☒ | U+2612 | `[×]` 로 풀어 쓰기 | |
| ❗ | U+2757 | `!` 또는 `※` (U+203B) | 이모지 |
| ❓ | U+2753 | `?` | 이모지 |
| ⟨ | U+27E8 | `〈` (U+3008) | 수학용 홑화살괄호는 없다. 한중일 괄호를 쓴다 |
| ⟩ | U+27E9 | `〉` (U+3009) | 위와 같다 |
| ⟶ | U+27F6 | `→` (U+2192) | 긴 화살표는 없다 |
| ↳ | U+21B3 | `→` (U+2192) | |
| ∙ | U+2219 | `·` (U+00B7) 또는 `•` (U+2022) | |
| ‣ | U+2023 | `•` (U+2022) | |
| ✦ | U+2726 | `◆` (U+25C6) | |
| ✧ | U+2727 | `◇` (U+25C7) | |
| ✱ | U+2731 | `*` (U+002A) 또는 `※` (U+203B) | |
| ∎ | U+220E | `■` (U+25A0) | |
| ️ | U+FE0F | 지우기 | 눈에 안 보이는 «이모지로 그려라» 표식. `⚠️` 를 붙여넣으면 딸려 온다 — `⚠` 만 남긴다 |

**이모지는 통째로 없다.** `📌 📝 🔥 🎯 💡 👉 🏫 📈 📉 😀 🇰🇷` … 전부. 리포트는 인쇄물이다.
이모지를 쓰고 싶으면 `★ ● ▶ ※` 같은 인쇄용 기호로 바꾼다.

## 3. 주석에도 특수 기호를 쓰지 않는다

서브세터는 **조판된 HTML 전체의 글자를 센다** — `subset_font.chars_of()` 가 `set(html)` 이다.
눈에 보이는 글자와 안 보이는 글자를 가리지 않는다. 그래서 이런 것들이 전부 걸린다.

- `assets/template*.html` 의 `<!-- ... -->` 주석
- `assets/themes/*.css` 의 `/* ... */` 주석 — 테마 CSS 는 HTML 안에 통째로 박힌다
- 화면에 안 쓰이는 `data-*` 속성, 꺼진 섹션 안의 글자

**왜 안 가리고 세나.** 가리려면 «이 글자는 인쇄에 안 나온다» 를 판정해야 하는데,
그것은 CSS 를 해석해야 아는 일이다(`display:none`, `::before` 의 `content`, 인쇄 전용 규칙).
틀리면 **두부가 인쇄되고, 인쇄한 뒤에 발견된다.** 그래서 더 넓게 세고, 대신 막을 때
어디인지를 말한다. 주석 몇 글자를 지우는 비용이 훨씬 싸다.

→ 판형·테마 주석은 **한글과 아스키만** 쓴다. 강조가 필요하면 `**굵게**` 나 `※` 를 쓴다.

## 4. 새 기호를 쓰기 전에 — 추측하지 말고 잰다

```
python scripts/subset_font.py --check "✓✗×○△"
```

한 글자씩 있음/없음과 대체안을 찍는다. 다른 굵기를 재려면 폰트 경로를 뒤에 붙인다.

## 5. 막을 뿐, 바꿔 주지 않는다

없는 글자를 만나면 렌더는 **멈추고**, 어느 글자·어디(판형/테마/데이터, 파일:줄)·주석인지
본문인지·무엇으로 바꾸면 되는지를 말한다. 그러나 **자동으로 바꾸지 않는다.**

국어 담당이 `<보기>` 판정에 적은 `✗` 가 아무 말 없이 `×` 로 둔갑해 학부모께 나가면,
그것은 폰트 사고보다 나쁜 사고다. 고치는 손은 사람의 손이어야 한다.

## 6. 표를 고쳤다면

이 표는 코드가 읽는다. 한 줄을 더하거나 고쳤으면 읽히는지 확인한다.

```
python -c "import sys;sys.path.insert(0,'scripts');import subset_font;print(len(subset_font.substitutions()),'줄')"
```
