# 문진 규격 — 언제 묻고, 무엇을 고르게 하나 (정본)

**묻는 것은 답이 산출물을 바꾸는 것만이다.** 나머지는 기본값으로 진행하고 «이렇게 했습니다» 라고 알린다.

> 옛 스킬은 학원명 → 로고 → 수준 → 섹션을 **네 번에 나눠** 물었다. 3회차쯤에 원장님이 지친다.
> 그렇다고 아무것도 안 물으면 엉뚱한 것이 나온다. **갈림길에서만, 선택지를 주고, 기본값과 함께** 묻는다.

도구는 `AskUserQuestion` 을 쓴다. 자유 입력으로 받지 않는다 — 선택지를 준다.
선택지가 있으면 원장님은 **고르기만** 하면 되고, 우리는 받은 값이 규격 안에 있음을 보장받는다.

---

## 묻는 자리 일곱

| # | 언제 | 무엇 | 안 물어도 되는 때 |
|---|---|---|---|
| **Q1** | 판독 직후 | 시험 정보가 맞는지 | — (항상 확인받는다) |
| **Q2** | Q1 직후 | 무엇을 만들지 (요약/상세/둘 다) | 이미 정해져 있을 때 |
| **Q3** | Q2 직후 | **디자인을 어떻게 할지** | 그 학원 테마가 이미 있을 때 |
| **Q4** | Q3 직후 | 넣을 섹션 (상세본일 때만) | 요약본만 만들 때 |
| **Q5** | 판독 신뢰도 낮은 문항이 있을 때 | 어떻게 처리할지 | `low` 가 없으면 건너뛴다 |
| **Q6** | 분석 끝난 뒤 | 킬러·이슈 문항 확정 | — (항상 확인받는다) |
| **Q7** | 상세본이고 등급컷을 켤 때만 | 산출 근거 | 기본은 꺼짐이라 대개 안 묻는다 |

**Q1~Q4 는 한 번에 묶어 묻는다.** 네 개를 한 화면에 올린다. 나머지는 그 단계에 도달했을 때만.

## Q1 — 시험 정보 확인

**읽어낸 값을 보여주고 맞는지만 받는다.** 원장님께 받아쓰게 하지 않는다.

> "시험지에서 이렇게 읽었습니다. 맞습니까?
> **삼성고등학교 · 1학년 · 2026 1학기 중간고사 · 영어 · 20문항 100점**"

| 선택지 | 뜻 |
|---|---|
| 맞습니다 | 그대로 진행 |
| 학교·학년이 다릅니다 | 되물어 고친다 |
| 과목이 다릅니다 | 되물어 고친다 |
| 문항 수·총점이 다릅니다 | **판독을 다시 한다** (배점 합이 안 맞으면 문항을 빠뜨린 것이다) |

---

## Q2 — 무엇을 만드나

| 선택지 | 설명 |
|---|---|
| **둘 다** (권장) | 요약본 1장 + 상세본. 학부모에겐 요약본, 상담엔 상세본 |
| 요약본만 | A4 한 장. 카톡·문자 첨부용 |
| 상세본만 | 정식 배포·보관용 |

기본값 **둘 다**. 한 번 돌려 두 벌이 나오므로 따로 만드는 것보다 싸다.

## Q3 — 디자인 ★

**이 질문을 건너뛰지 않는다.** 학원마다 표지에 찍히는 이름과 색이 다르고,
한 번 정하면 그 학원의 모든 리포트가 그 색으로 나간다.

| 선택지 | 무엇 | 언제 |
|---|---|---|
| **gonggam-navy** | 네이비 + 벽돌빨강 | **학생관리 보고서 톤.** 제목 앞 세로 막대 · 네이비 표 머리글 · 핵심은 분홍 바탕 |
| **nelt** | 파랑 + 주황 · 흰 카드 | **NELT 리포트 톤.** 요즘 앱·블로그 카드 꼴. 그림자와 여백이 넉넉하다 |
| **clean** | 흰 바탕 · 남색 | 기본. 어느 학원에나 무난하다 |
| **gonggam** | 공감 민트·에메랄드 | 공감에듀테크 자체 발행 |
| **mono** | 무채색 | **흑백 복사를 거치는 문서.** 색이 사라져도 구분이 선다 |
| **warm** | 아이보리 · 브라운 | 초등·중등 학부모 |
| **우리 학원 색으로** | 색 두 개를 받아 테마를 새로 만든다 | 브랜드가 있는 학원 |

> **이 표는 `assets/themes/` 안의 파일과 같아야 한다.** 테마를 새로 지어 놓고 이 표에
> 안 적으면 **원장님께 그 선택지가 보이지 않는다** — 파일은 있는데 고를 길이 없다.
> `gonggam-navy` 와 `nelt` 가 실제로 그렇게 묻혀 있었다(2026-09-23 에 드러났다).
> 새 테마를 지으면 **같은 걸음에** 이 줄을 늘린다.
>
> 무엇이 있는지 헷갈리면 세지 말고 물어본다 — `python scripts/render_report.py --list-themes`

### 「우리 학원 색으로」를 고르면

색 두 개만 받는다. 나머지는 **기계가 만든다** — 원장님이 색을 열 개 고르게 하지 않는다.

```
주색(primary)   표지 바탕 · 제목 · 표 머리글
강조색(accent)  콜아웃 · 강조 배지
```

파생 규칙(고정):

| 변수 | 만드는 법 |
|---|---|
| `--primary-pale` | 주색을 밝기 92% 로 |
| `--cover-bg` | 주색과 그보다 18% 어두운 색의 그러데이션 |
| `--accent-pale` | 강조색을 밝기 94% 로 |
| 나머지 회색 | `clean` 의 값을 그대로 물려받는다 |

결과는 `assets/themes/<학원명>.css` 로 저장한다. **한 번 만들면 다음부터 안 묻는다.**

### 대비 검사 — 통과 못 하면 되묻는다

- 본문 글자와 바탕의 명도 대비가 **4.5 : 1 미만**이면 그 색을 쓰지 않는다
- 흑백으로 변환했을 때 주색과 강조색의 **명도 차가 20% 미만**이면 되묻는다
  (복사기를 거치면 두 색이 같은 회색이 된다)

> 학원 문서는 복사기를 거친다. **색만으로 구분하면 사라진다.**
> 대비 검사는 미감이 아니라 읽히느냐의 문제다.

### 로고

같은 화면에서 함께 받는다.

| 선택지 | 처리 |
|---|---|
| 로고 파일이 있습니다 | 경로를 받아 표지에 박는다 |
| 밝은 배경 로고 / 어두운 배경 로고 | 흰 박스로 감쌀지 결정 |
| 없습니다 | 학원명 텍스트로 대체 |

## Q4 — 넣을 섹션 (상세본일 때만 · 복수 선택)

고정 다섯은 묻지 않는다: 표지 · 시험 개요 · 문항별 분석표 · 유형별 분포 · 총평.

| 선택 섹션 | 기본 |
|---|---|
| 출제 범위별 비중 | 켜짐 |
| 난이도 분석 | 켜짐 |
| 킬러문항 심층 | 켜짐 |
| 다음 시험까지 학습 계획 | 켜짐 |
| 가정에서 도와주실 것 | 켜짐 |
| 예상 등급 구간 | **꺼짐** (§ Q7) |

**뺀 섹션은 통째로 사라지고 번호와 쪽수가 다시 매겨진다.** 얇아지는 만큼 인쇄비가 준다.

## Q5 — 판독이 흐린 문항이 있을 때

`confidence: "low"` 가 하나라도 있으면 **반드시 묻는다.** 게이트가 그 전에는 통과시키지 않는다.

> "3번·14번을 또렷하게 읽지 못했습니다.
> 14번은 ③번 선지 뒷부분이 그림자에 가렸습니다."

| 선택지 | 결과 |
|---|---|
| 다시 찍어 올리겠습니다 | 그 장만 다시 받는다 (권장) |
| 그대로 진행 | 리포트에 «판독 확인 필요» 표시가 남는다 |
| 그 문항은 빼고 진행 | 문항 수·배점 합계에서 제외하고 그 사실을 적는다 |

**조용히 진행하는 선택지는 없다.**

## Q6 — 킬러·이슈 문항 확정

기계가 고른 결과를 보여주고 확인받는다.

> "킬러문항은 규칙으로 골랐습니다 — 난이도 `상` 중 배점이 높은 순.
> **11번(5점) · 15번(4점) · 25번(6점)**"

| 선택지 | 결과 |
|---|---|
| 그대로 갑니다 | 진행 |
| 다른 문항으로 바꾸겠습니다 | 번호를 받아 교체하고 «수동 선정» 으로 표시 |
| 개수를 조정하겠습니다 | 3~5개 사이에서 |

이어서 **이슈 문항**을 묻는다. 이건 기계가 못 찾는다 — 강사만 안다.

| 선택지 | 뜻 |
|---|---|
| 없습니다 | 그 섹션을 빼고 진행 |
| 복수정답 / 조건누락 / 범위밖 / 배점과다 / 유형급변 | 번호와 이유 한 줄을 받는다 |

**이슈 갈래는 닫힌 목록이다.** 목록 밖이면 «없음» 으로 처리하고 그 사실을 알린다.

## Q7 — 등급컷 (켤 때만)

기본은 **꺼짐**이다. 켜겠다고 하면 근거를 받는다.

| 받는 것 | 없으면 |
|---|---|
| 표본 (몇 명 기준인가) | **켜지 않는다** |
| 기간 (어느 회차 자료인가) | **켜지 않는다** |
| 출처 (어디서 온 숫자인가) | **켜지 않는다** |

근거 없는 숫자가 학원 이름으로 학부모에게 나가면 표시광고법 문제가 된다.
셋을 다 받으면 리포트에 그 셋을 함께 싣고 «예상치» 고지를 붙인다.

## 묻지 않는 것

| 묻지 않음 | 왜 |
|---|---|
| 문항의 유형·난이도 | 스킬이 판정한다. 그러라고 있는 것이다 |
| 쪽수·섹션 번호 | 기계가 센다 |
| 파일 이름 | 규격이 정한다 |
| 폰트 | 동봉 woff2 고정. 바꾸면 쪽수가 달라진다 |
| 「이 정도면 됐나요?」 | 게이트가 판정한다. 사람에게 떠넘기지 않는다 |

## 되묻는 순간 — 묻지 않고 진행하려 할 때 멈춘다

아래를 하려 하면 **자동으로 되묻는다.** 원장님이 지적해 주길 기다리지 않는다.

| 하려는 것 | 되물을 말 |
|---|---|
| 배점 합이 총점과 안 맞는데 넘어간다 | 「문항을 빠뜨린 것 아닌가요?」 |
| 흐린 문항을 짐작으로 채운다 | 「다시 찍어 주시겠습니까?」 |
| 색을 내가 고른다 | 「학원 브랜드 색이 있으신가요?」 |
| 등급컷을 근거 없이 넣는다 | 「이 숫자의 출처가 어디인가요?」 |
| 이슈 문항을 내가 판정한다 | 「선생님이 보시기에 문제된 문항이 있나요?」 |
