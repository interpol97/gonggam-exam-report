# 판독 규약 — 사진·스캔·PDF

**외부 OCR 엔진을 쓰지 않는다.** Opus 비전이 직접 읽는다.
표·수식·밑줄·네모는 문맥과 같이 봐야 뜻이 통하는데, 글자만 뽑아내는 엔진은 그걸 못 한다.

대신 **모르는 것을 모른다고 적는 규율**이 필요하다. 그게 이 문서다.

---

## 1. 입력 갈래

| 입력 | 처리 | 주의 |
|---|---|---|
| 텍스트 PDF | 그대로 읽는다 | 단 **2단 조판**은 읽는 순서가 꼬인다. 단마다 따로 읽는다 |
| 스캔 PDF | 페이지를 이미지로 뽑아 비전으로 | 기울기·얼룩 |
| 사진 | 비전으로 직접 | 그림자·손가락·접힌 자국 |

## 2. 사진은 장당 한 면

한 장에 두 면이 들어오면 **나눠 달라고 요청한다.**
쪼개진 문항 번호가 섞이면 뒤의 분석이 전부 어긋난다. 여기서 아끼면 나중에 두 배로 든다.

받을 때 확인할 것:
- 페이지 번호가 보이는가 (순서를 맞출 유일한 단서)
- 문항 번호가 잘리지 않았는가
- 배점 표시 `[3점]` 이 보이는가

## 3. `confidence` 는 의무다

문항마다 `high` 또는 `low` 를 적는다. **`low` 를 적는 것이 실패가 아니다.
적지 않고 넘어가는 것이 실패다.**

`low` 로 적어야 하는 때:

- 글자가 뭉개졌거나 그림자에 먹혔다
- 문항이 페이지 경계에서 잘렸다
- 그림·도표가 있어야 뜻이 통하는데 안 보이거나 흐리다
- 선지 개수가 다섯이 아닌데 왜인지 모르겠다
- 배점이 안 보인다

같이 `note` 에 **무엇이 안 보이는지** 적는다.

```json
{"no":14,"confidence":"low","note":"③번 선지 뒷부분이 그림자에 가림. 배점 표시 안 보임"}
```

게이트가 `low` 를 세어서 **원장님께 되묻게 만든다.** 확인을 받으면
`report.json` 에 `"low_confidence_reviewed": true` 를 적는다. 그 전에는 통과하지 않는다.

## 4. 지어내지 않는다

판독이 안 되는 자리는 **`[판독불가]`** 로 남긴다.
그럴듯하게 채워 넣으면 나중에 아무도 그게 지어낸 것인지 모른다.
기출 DB 에 지어낸 문장이 한 줄 들어가면 그 학교 자료 전체를 못 믿게 된다.

## 5. 정답을 모를 때

정답표가 시험지에 없으면 **풀어서 낸다.** 단:

- `"answer_source": "추론"` 으로 표시한다
- 해설 MD 제목 줄에 `(추론 정답 — 학교 정답표 미확인)` 을 붙인다
- 게이트가 주의로 잡아 준다
- 학교 정답표를 받으면 덮어쓰고 표시를 지운다

## 6. 읽는 순서

1. **표지·머리글 먼저** — 학교·학년·학기·과목·시험명·총점·시간
   여기서 읽히는 값은 원장님께 받아쓰게 하지 않는다. 읽어서 보여 드리고 «맞습니까» 만 받는다
2. **문항 번호와 배점을 먼저 훑는다** — 총 문항 수와 배점 합을 먼저 잡는다.
   합이 총점과 안 맞으면 **그 시점에 멈춘다.** 문항을 빠뜨렸다는 뜻이다
3. 그다음 문항 본문
4. 마지막에 정답표·답안지

배점 합 검사를 마지막에 하면 **전부 읽고 나서 다시 읽게 된다.** 먼저 맞춘다.

## 7. 과목별로 특히 놓치는 것

| 과목 | 놓치기 쉬운 것 |
|---|---|
| 영어 | 밑줄·네모의 **위치**. 어법 문항은 어디에 그어졌는지가 문제 자체다 |
| 수학 | 그림의 **길이·각도 표시**. 첨자와 지수 구분 |
| 국어 | `<보기>` 상자. 지문과 보기를 섞으면 문항이 무의미해진다 |
| 과학 | 그래프 **축 이름과 단위**. 표의 실험군·대조군 구분 |
