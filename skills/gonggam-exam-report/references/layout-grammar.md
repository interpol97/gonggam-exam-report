# 지면 문법 — 원장님 보고서 두 장에서 뽑은 것

> 색은 `themes/*.css` 가 정본이다. **이 문서는 «배치»만 다룬다** — 무엇을 어디에 놓고,
> 무엇을 크게 하고, 무엇을 나란히 두는가. 색 값을 여기 적지 않는다.

본본 둘:

| 이름 | 무엇 | 색 계열 |
|---|---|---|
| **A. 학생관리 보고서** (충암고2, 2쪽) | 수업 한 회차 기록 — 카드·논리 3단·막대·표·첨부 격자 | 네이비 + 벽돌빨강 |
| **B. NELT 리포트 요약** (1쪽) | 시험 결과 요약 — 도넛·레이다·막대·2×2 카드 | 파랑 + 주황 |

둘은 색이 다르고 소재가 다른데 **배치 문법이 거의 같다.** 그 겹치는 부분이 규격이다.

---

## 0. 관통하는 원칙 넷

1. **숫자는 크게, 단위는 작게 붙여서 한 덩어리로.** `3` + `지문` 을 따로 두지 않는다
2. **강조는 한 곳만.** 카드 넷 중 하나, 논리 셋 중 하나, 막대 일곱 중 하나
3. **제목줄은 좌우 양끝을 쓴다.** 왼쪽 제목 / 오른쪽 작은 메타
4. **선의 뜻을 섞지 않는다.** 실선 = 섹션 경계, 점선 = 카드 안 소구분, 굵은 세로선 = 인용

## 1. 머리띠 — 표지가 아니라 띠다 ★

**본본 A 에는 표지 장이 없다.** 첫 장 맨 위의 전폭 띠가 표지 노릇을 한다.
2쪽에도 같은 띠가 다시 온다(제목만 짧게). 그래서 **어느 장을 뽑아 봐도 누구 것인지 안다.**

```
┌──────────────────────────────────────────────────┐  ← 전폭. 좌우 여백 밖까지
│ 개 미 지 옥  학생관리 · 학습 관리 보고서          2026. 08. 31.│  kicker 11px/.18em
│ 충암고 2학년 정찬진  어법 변형 / 1회차   2025 고2 9월 학평 …│  제목 30px/800
│                                        50·51·52번 어법 변형│  메타 우측정렬 3줄
└──────────────────────────────────────────────────┘
═══════════════════════════════════════════════════   ← 강조색 4px
```

- 왼쪽: **kicker**(작게·자간 넓게·흐리게) → **제목**(가장 큼) → **부제는 제목 옆에 인라인**으로 붙인다(줄을 새로 쓰지 않는다)
- 오른쪽: 우측정렬 메타 3줄. **첫 줄만 굵고**, 나머지는 흐리다
- 띠 아래 **강조색 가는 줄** — 이 톤의 서명

```css
.hdr{display:flex;justify-content:space-between;align-items:flex-end;
  background:var(--primary);color:#fff;padding:22px 28px 18px;
  margin:-20px -12px 0;border-bottom:4px solid var(--accent)}
.hdr .kick{font-size:11px;letter-spacing:.18em;opacity:.72;margin-bottom:7px}
.hdr h1{font-size:30px;font-weight:800;letter-spacing:-.025em}
.hdr h1 small{font-size:17px;font-weight:500;opacity:.82;margin-left:9px}
.hdr .meta{text-align:right;font-size:12.5px;line-height:1.62;opacity:.78}
.hdr .meta b{display:block;font-size:15px;opacity:1;margin-bottom:3px}
```

**우리 판형과 다른 점** — 우리는 `.cover` 가 가운데 정렬 라운드 상자다. 그건 그대로 두되(학부모 배포용 첫인상),
**2쪽부터 이 머리띠를 얹는다.** 지금은 2쪽 이후에 아무 표시가 없어 낱장으로 흩어지면 출처를 잃는다.

## 2. 섹션 제목줄 — 좌우 양끝

```
▌오늘의 핵심 — It ~ that 강조구문과 가주어·진주어 구별      51번 / 25년 9월 23번 첫 문장
└ 4px 세로 막대                                          └ 12px 흐린 글씨, 우측정렬
──────────────────────────────────────────────────────────  ← 아래 실선 1px
```

오른쪽 메타는 **장식이 아니라 출처**다. 「이 섹션이 어디서 나온 이야기인가」를 적는다.
적을 것이 없으면 **비워 둔다.** 채우려고 지어내지 않는다.

우리 판형에 `.sec-head` / `.section-title` / `.page-mark` 가 이미 있다. **`.page-mark` 를 출처 자리로 쓴다.**

## 3. 숫자 카드 — 값과 단위는 한 덩어리 ★

본본 A 첫 줄, 본본 B 의 「총 35분 44초」가 같은 규칙이다.

```
┌────────────┐ ┌────────────┐ ┌────────────┐ ┌════════════┐
│ 3지문       │ │ 35개       │ │ 14개       │ ║ It ~ that  ║  ← 넷째만 강조
│ 다룬 지문…  │ │ 교정한 어법…│ │ 최다 오류…  │ ║ 강조 vs 가주어║
└────────────┘ └────────────┘ └────────────┘ ╚════════════╝
```

- 값 **46px / 900**, 단위 **15px / 700** 을 같은 줄에 **간격 2px** 로 붙인다 (`align-items:baseline`)
- 라벨은 아래 **12.5px 흐린 글씨** 한 줄
- **마지막 카드 하나만** 강조 바탕 + 강조 글자. 거기엔 숫자가 아니라 **말**이 들어간다 — 「오늘의 핵심」

```css
.info-card .value{display:flex;align-items:baseline;gap:2px;
  font-size:46px;font-weight:900;letter-spacing:-.04em;line-height:1}
.info-card .unit{font-size:15px;font-weight:700}
.info-card .label{margin-top:9px;font-size:12.5px;color:var(--muted)}
.info-card.key{background:var(--accent-pale);border-color:#F2D6D1}
.info-card.key .value{font-size:21px;line-height:1.3;color:var(--accent)}
```

**넷 중 하나 규칙을 어기지 않는다.** 둘을 강조하면 둘 다 안 보인다.

## 4. 카드 머리띠

강조 카드는 **상단에 색 띠**를 두르고, 그 띠가 좌우 양끝을 쓴다.

```
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ 학생이 놓친 자리 — what 을 그대로 두었음   필기 원본 발췌 ┃ ← 강조색 면, 흰 글자
┡━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┩
│ (내용)                                              │ ← 강조색 2px 테두리
└──────────────────────────────────────────────────┘
```

왼쪽은 **무엇인지**, 오른쪽은 **어디서 온 것인지**. 우리 `.problem .head` 가 이 꼴이다 — 오른쪽 칸만 없다.

## 5. 논리 3단 — 가운데만 강조 ★

본본 A 의 핵심 장치. 판단 절차를 **세 칸으로 갈라 놓고, 실제로 갈린 칸만 강조**한다.

```
┌─ ① ─────────┐ ┏━ ② ━━━━━━━━━┓ ┌─ ③ ─────────┐
│ It is 와 that │ ┃ It is 뒤 요소의┃ │ that 뒤 절의  │
│ 을 지워본다   │ ┃ 품사를 본다   ┃ │ 완전성을 본다 │
│ (설명)       │ ┃ (설명)       ┃ │ (설명)       │
│ ┄┄┄┄┄┄┄┄┄ │ ┃ ┄┄┄┄┄┄┄┄┄ ┃ │ ┄┄┄┄┄┄┄┄┄ │ ← 점선
│ → 문장이 깨진다│ ┃ → 가주어      ┃ │ → what ✗/that ✓│ ← 결론, 강조색
└─────────────┘ ┗━━━━━━━━━━━━━┛ └─────────────┘
```

- 번호는 **원형 배지**(22px 원, 진한 바탕, 흰 숫자 900)
- 결론 줄은 **화살표로 시작**하고 강조색·굵게
- 강조 칸은 바탕 + 2px 테두리

우리 `.steps` 는 세로 목록이다. **킬러문항의 「푸는 순서」가 바로 이 꼴**이라 카드 3단으로 바꿀 자리다.
단 **단계가 넷 이상이면 세로 목록으로 돌아간다** — 3단 격자는 셋일 때만 읽힌다.

## 6. 가로 막대 — 강조는 «1위» 가 아니라 «지목한 것» ★

```
    분사 (능동/수동) ████████████████████████  10
           수일치 ██████████████             6
           대명사 ████████████               5
   접속사 · 관계사 ███████                    4   ← 이 행만 강조색 (4개인데도)
```

**본본 A 는 1위를 칠하지 않았다.** 1위(분사 10개)는 「스스로 교정한 것」이라 문제가 아니고,
4개짜리 접속사·관계사가 「전부 한 지문에 몰려 있고 모두 놓친 것」이라 칠했다.
아래 주석이 그 이유를 말한다 — *「개수보다 적중률이 문제인 영역」*.

> **우리 판형의 결함**: `themes/gonggam-navy.css` 가 `.bar-row:first-of-type` 을 강조색으로 칠한다.
> 이건 **1위 자동 강조**라 본본의 규칙과 다르다. 데이터가 「어느 행이 문제인가」를 말해야 한다.
> `report.json` 의 막대 행에 `emphasis: true` 를 받고, CSS 는 `.bar-row.em` 을 칠한다.
> 아무 행에도 없으면 **아무 것도 칠하지 않는다.** 1위를 대신 칠하지 않는다.

격자는 `라벨 104px(우측정렬) / 트랙 1fr / 값 34px(우측정렬)`. 값은 **트랙 밖 오른쪽**에 둔다.

막대 아래에는 **한 문장짜리 해석**을 붙인다. 숫자만 두면 읽는 사람이 결론을 못 낸다.

## 7. 인용 지면 — 원문·정답·근거 셋을 다른 꼴로

```
┌ 흰 바탕, 얇은 테두리, 줄간 1.9 ──────────────────┐
│ It's conceivable ▒what▒ in a world ▒which▒ …   │  ← 하이라이트 = 배경 span
└──────────────────────────────────────────────┘
  51번 원본 · 붉은 음영 = 오류 지점 / 붉은 펜 = 학생 필기   ← 11px 캡션 = 범례
┃ 정답 문장                                        ← 굵은 세로선 4px + 옅은 바탕
┃ It's conceivable **that** in a world **where** …
```

- 원문은 **줄간을 넓게**(1.9) 준다. 손으로 표시할 자리가 필요해서다
- **캡션이 범례다.** 색을 썼으면 그 색이 무슨 뜻인지 바로 아래 11px 로 적는다. 이걸 빠뜨리면 빨간 표시가 무슨 뜻인지 아무도 모른다
- 정답 문장은 **면이 아니라 세로선**으로 연다

## 8. 표

머리글 **진한 바탕 + 흰 글자**, 본문은 얼룩을 아주 옅게. 셀 세로 여백 넉넉히(12px).
교정표라면 **첫 열 = 취소선 원문**, **둘째 열 = 강조색 굵은 정답**, **셋째 열 = 판단 근거**.
근거 열이 없으면 표를 쓰지 않는다 — 정답만 나열한 표는 학생이 못 배운다.

## 9. NELT 에서 더 가져올 것 둘

### 9-1. 비대칭 2열 — 좁은 라벨 칸 + 넓은 내용 칸

```
┌──────────┬──────────────────────────────────┐
│ 종합 평가 결과│ 동 학년 대비 나의 실력 비교          │  ← 둘 다 옅은 색 띠
├──────────┼──────────────────────────────────┤
│  (도넛)   │  (꺾은선 + 범례 우측 상단)            │
└──────────┴──────────────────────────────────┘
```

왼쪽 **150px 고정**, 오른쪽 나머지. 왼쪽엔 결론 하나(등급·수준), 오른쪽엔 근거(그래프).
**결론이 왼쪽에 먼저 온다** — 그래프를 읽을 줄 몰라도 왼쪽만 보면 된다.

### 9-2. 2×2 카드 — 머리에 옅은 색 띠, 발에 점선 + 2열 수치

```
┌───────────────────────┐
│ 어휘  중학교 1학년 수준    │ ← 옅은 강조색 띠, 제목 옆에 «수준» 을 인라인
├───────────────────────┤
│      (그래프)           │
│ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ │ ← 점선
│ Vocabulary │ 동 학년 석차 │ ← 라벨 작게 흐리게
│  약 1800단어 │  상위 95%   │ ← 값 크게 강조색
└───────────────────────┘
```

우리 **난이도 5단** 과 **과목별 축** 이 정확히 이 꼴에 맞는다.

## 10. 꼬리말

```
────────────────────────────────────────────────────
개미지옥 학생관리 · 충암고2 정찬진 · 2026.08.31            1 / 2
```

얇은 선 위, 왼쪽 메타 / 오른쪽 쪽번호. **현재 쪽만 굵게**, 총 쪽수는 흐리게.
쪽번호는 렌더러가 PDF 를 재서 박는다(SKILL.md §6-4). 여기서 세지 않는다.

## 11. 하지 않을 것

- **강조를 둘 이상 두지 않는다.** 카드 넷 중 둘을 칠하면 둘 다 안 보인다
- **1위를 자동으로 칠하지 않는다.** 칠할 행은 데이터가 지목한다(§6)
- **색을 쓰고 범례를 안 붙이지 않는다.** 하이라이트를 썼으면 11px 캡션이 따라온다(§7)
- **3단 격자에 넷을 넣지 않는다.** 넷부터는 세로 목록
- **점선과 실선을 바꿔 쓰지 않는다.** 실선은 섹션, 점선은 카드 안
- **근거 열 없는 교정표를 만들지 않는다**(§8)
- 라운드를 키우지 않는다. 본본 둘 다 **10~12px** 이고 그 이상은 보고서 꼴이 아니다
